Computer Technology — Module 1

Introduction to Computer Systems

A computer system is an electronic system that receives data, processes information, stores information, and produces useful results.

Computer systems are made of hardware and software. Hardware refers to physical components such as the processor, memory, storage, keyboard, mouse, and monitor.

Software consists of instructions and programs that tell computer hardware what to do.

Learning Objective

After this lesson, you should be able to explain the difference between hardware and software and identify common computer components.
