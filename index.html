🛡️ About CyberShield Lab

CyberShield Lab is an educational cybersecurity simulation. It demonstrates concepts such as threat detection, simulated file infection, network visualization, system monitoring, event logging, and incident cleanup.

What this application DOES

  • Creates fake data inside the webpage
  • Simulates malware behavior
  • Displays artificial network nodes
  • Generates simulated system statistics
  • Demonstrates threat detection concepts

What this application DOES NOT DO

  • It does not access your files
  • It does not delete files
  • It does not encrypt files
  • It does not scan Wi-Fi networks
  • It does not attack devices
  • It does not spread to other computers
  • It does not install software
  • It does not bypass antivirus software
